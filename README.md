## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/MIAN0078/my-portfolio.git
cd my-portfolio
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open your browser and visit:

```bash
http://localhost:3000
```
